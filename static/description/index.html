How It Works

1
Install & Configure

Go to Website > Configuration > Settings and enable "Google Preferred Source".

2
Choose Integration Mode

Select Standard JS Badge, Advanced Manual JS, or Deeplink mode with theme preference.

3
Engage Readers & Shoppers

Visitors click to add your domain directly into Google Source Preferences.
